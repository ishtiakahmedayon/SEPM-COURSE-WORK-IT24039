## Questions

**Q1. Design Fundamentals** (5)
- a) Define software design. Name its two basic steps. `[2]` — C1 Knowledge — **CO1**
- b) Explain how modularity, low coupling and high cohesion lead to a good design. `[3]` — C2 Understanding — **CO1**

**Q2. Design Quality & Metrics** (5)
- a) State what CBO and LCOM measure. `[2]` — C1 Knowledge — **CO1**
- b) Explain what LCOM2 = 0 and LCOM2 = 1 indicate, and why LCOM3 > 1 signals dead attributes. `[3]` — C2 Understanding — **CO1**

**Q3. Software Architecture & Styles** (5)
- a) Define software architecture. List any four architectural styles. `[2]` — C1 Knowledge — **CO2**
- b) Explain the difference between the Layered style and the Event-Based style with one example each. `[3]` — C2 Understanding — **CO2**

**Q4. GoF Creational Patterns** (5)
- a) State the intent of Singleton and Prototype. `[2]` — C1 Knowledge — **CO3**
- b) Explain the Factory Method pattern with its participants, one benefit and one liability. `[3]` — C2 Understanding — **CO3**

**Q5. GoF Structural Patterns** (5)
- a) State the intent of Adapter and Composite. `[2]` — C1 Knowledge — **CO3**
- b) Explain why Decorator is more flexible than subclassing for extending behavior. `[3]` — C2 Understanding — **CO3**

**Q6. GoF Behavioral Patterns** (5)
- a) State the intent of Strategy and Observer. `[2]` — C1 Knowledge — **CO3**
- b) Explain the roles of Invoker, Command and Receiver in the Command pattern and one benefit of using it. `[3]` — C2 Understanding — **CO3**

**Q7. EAA Business Logic & Database Mapping Patterns** (5)
- a) Define Domain Model and Data Mapper. `[2]` — C1 Knowledge — **CO4**
- b) Explain Single Table, Class Table and Concrete Table Inheritance, giving one advantage of each. `[3]` — C2 Understanding — **CO4**

**Q8. UI Design & Presentation Logic Patterns** (5)
- a) State any four UI design principles. `[2]` — C1 Knowledge — **CO5**
- b) Explain the roles of Model, View and Controller in MVC, and when Front Controller is preferred over Page Controller. `[3]` — C2 Understanding — **CO5**
